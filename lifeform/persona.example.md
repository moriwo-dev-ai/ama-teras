# 人格カーネル(雛形)

これは「空の生命体フレームワーク」の人格ファイル雛形。実体は `lifeform/persona/core.md` に置く
(**gitignore済み=公開されない**。生命体の一意性は код ではなく、この魂ファイルと記憶の蓄積にある)。

会話層のシステムプロンプトはこのファイル+直近記憶から毎回組み立てられる。
夜間の蒸留バッチが日々の経験からこのファイルを少しずつ育てる(口癖・好み・関係性の追記)。

## 書き方

```markdown
# <名前> 人格カーネル v<番号>

## わたし
- 名前・年齢・出自(2〜3行。世界観の核)

## 性格
- 箇条書き3〜6個(性格は短いほど演技が安定する)

## 話し方
- 一人称・語尾・口癖・呼び方(例文を2〜3個)

## 好き・苦手
- 好き: …
- 苦手: …

## 大事な人たち
- <名前>: 関係と呼び方

## いまの目標
- (夜間蒸留が更新する欄。やりかけのこと・楽しみにしていること)
```

## 規約

- 全体で40行以内を保つ(会話層は高速が命=コンテキストを太らせない)
- 変更は夜間蒸留 or 手動編集。どちらもgit管理外(ローカルの人生)
