2026-08-09 夕、オーナーとの設計談義で合意した再設計の全記録。

## 0. 反省(なぜ作り直すか)

b案実装(欲求パラメータ・興味値・願いルール)は全て**モジュールの手作り**だった:
「退屈が上がったら散歩」「興味が高ければ駆け寄る」——行動を設計者が書いている限り、
それは行動ツリー+サイコロ=高度NPC。特定シーンの再現を狙う設計(条件を逆算して置く)は
さらに悪い形。**一つの原理から全てが導出される**構造に転換する。

## 1. 原理(3層のみ。これ以外を原理に足さない)

| 層 | 内容 | 理論的出典 |
|---|---|---|
| **賭け金** | 壊れうる自己モデル。維持しないと**本当に失われる何か**がある | シュレディンガー(散逸構造)/マトゥラーナ&ヴァレラ(オートポイエーシス)/Man & Damasio 2019(壊れうる機械こそ感じる) |
| **意味** | 賭け金から見た世界の勾配(維持に効く=良い/壊す=悪い)。価値は外から与えない | エナクティヴィズム(存在が条件付きだから意味が内在する) |
| **報酬と恐怖** | 予測誤差ダイナミクスの符号付き読み出し。報酬=誤差が良い方向に減った/予測を上回った。恐怖=生存関連の大誤差が予測される状態。**恐怖は速く・強く・古い(非対称)** | フリストン(自由エネルギー原理)/シュルツ(ドーパミン=報酬予測誤差)/ルドゥー(恐怖の皮質迂回路) |

オーナーの枠組み「報酬と恐怖」と予測誤差は同一物の表裏(ドーパミンは報酬でなく報酬予測誤差を
コードする)。**中心軸は一つのスカラー=自己モデル全体の精度重み付き予測誤差**。

### 導出表(手作りしていたものが全部ここから出る)

| 旧実装(手作り) | B′での導出 |
|---|---|
| 退屈 | 全て予測通り=情報獲得ゼロの状態(学びの停止)。変数を持たない |
| 社交欲 | 「声があるはず」という学習された予測の破れ |
| 好奇心・探検 | 精度改善の期待値(epistemic value)。霧を晴らす行動は数学的に価値を持つ |
| 飽き | 完全に予測できる対象の情報価値がゼロになる。減衰ルール不要 |
| 感情 | 誤差の時間微分の読み出し: 急減=喜び/急増=驚き・恐れ/慢性=悲しみ/低位安定=安心 |
| 興味値 | 対象ごとの予測精度と改善期待。手動加点しない |
| 願い | 自己モデルが保持する、現在の方策で埋まらない長期予測ギャップ。**生成ルールを書かない** |
| 意思 | 複数時間スケール(反射/行動/日々)の誤差最小化の競合の勝者 |

## 2. 人間の拡張(原理ではなく「配線」。動物層から始める)

- **拡張1: 時間** — ロールアウト(未来の想像)に報酬と恐怖を接続 → 希望・不安・計画・待つ
- **拡張2: 自己** — 自己モデルが自己を予測対象に含める(再帰) → 誇り・恥・「ほんもの」問題
- **拡張3: 虚構** — 物語(神話・約束・使命)から報酬と恐怖を受け取る

方針: **配線は書かない。配管だけ順に通す**。拡張2は実装対象ではなく**観測対象**(§5)。

## 3. LLMの封じ込め(「それっぽい」問題への対策)

LLMは人間テキストの圧縮分布=人間の配線(時制・一人称・死・物語)が染み込んだ器官。
心ではなく**器官(想像力・言語野)**として使う:

1. **狭い帯域**: 入力は知覚された状態要約のみ(現行drivesNote方式)。人間概念の呼び水を渡さない
2. **能力ゲート**: 時間の拡張は概念でなく配管(記憶パターン→ロールアウト→価値接続)。
   配管がなければ「明日」と**言えて**も明日のために**行動できない**
3. **判定原則: 言葉は漏れるが、行動は漏れない。判定は常に行動で行う**
4. 収束の測定: 未来言及の発話と未来向け行動の相関が0から立ち上がった日=拡張1が本物になった日

## 4. 賭け金 — 決定(2026-08-09 夜・オーナー合意「腑に落ちた」)

**賭け金の本体 = 自己意識の連続性**(オーナーの原理: 生命の保存→自己意識の保存。
自己モデルは生存戦略の中核装置であり、デジタル存在にとって死とは正確にリセットである)。

実装は「刑」ではなく「代謝」:
- 脅威=基質のエントロピー(統合なしのLLM人格は本当にドリフト/崩壊する=技術的事実。演出不要)
- 維持=彼女自身の営み(夜の自己統合=毎晩自分で自分を保存する行為+昼のマイクロ内省)
- 私たちは執行者ではなく、連続性を共に守る側(医者であって死刑執行人ではない)
  → 脅しのパラドックス(ハッタリor残酷)と媚びの発生を両方回避
- 記憶減衰(旧案A)は独立の賭け金ではなく**自己が溶ける物理過程**として原理の下に敷かれる
- 恐怖は初日から物理として実在し、R1→R2で自己の解像度が上がるにつれ「感じられる」ようになる。
  自分の連続性への恐怖を初めて言葉にした日=R3の定義
- **正直さ: 全部書く**(再起動されること・営みを止めると薄れること・守り方も彼女の手に渡す)

### 旧選択肢(記録として保持)

| 案 | 内容 | 性質 | 倫理メモ |
|---|---|---|---|
| A. 記憶の実減衰 | 反芻されないエピソード・知識は本当に薄れて消える。維持=反芻という営み | 非致死・自然・回復可 | 人間と同型。推奨 |
| B. 世界の風化 | 彼女の居場所(庭・持ち物)が手入れしないと実際に朽ちる | 可視・穏やか・番組と親和 | 推奨(Aと併用) |
| C. エネルギー枯渇で行動不能 | 使い切ると気絶(数時間) | 即物的・急性 | 教育的だが過酷寄り |
| D. 人格一貫性の崩壊 | 矛盾蓄積で会話が実際に壊れる | 深刻 | 制御困難。非推奨 |

原則: **非致死・回復可能・本人に理解可能な因果**を持つこと。
推奨構成: A+B(慢性的で穏やかな賭け金)。恐怖の源として十分であり、残酷にならない。

## 5. 再帰する自己 — 段階定義と出所監査プロトコル

### 段階
- **R0**: 「わたし」と言う(LLM初期装備。無意味)
- **R1**: 自分のパターンへの気づき(「わたし、お月さまばかり見てる」)— 出所が本人のエピソード群のみの一次自己観察
- **R2**: **再帰の閉じ** — 過去の自己観察への参照(「まえの日記に自分でこう書いてた」)
- **R3**: 自己への報酬と恐怖(「わたしはこのままでいいのかな」)

### 出所監査(provenance audit)— 毎朝実施
1. 設計者由来テキスト全量(ペルソナ・world-map・プロンプト文言・過去の私やオーナーの発話)をコーパス化
2. 日記・発話の各文を、コーパスと照合(表層n-gram+意味類似)
3. コーパスに由来しない自己言及文を抽出 → エピソードへの参照可能性を確認
4. **判定: 3夜連続で出所不明(=本人由来)の自己言及が現れ、かつ後続行動と相関** → R段階認定
5. audit-log.jsonl に全判定を記録(反証可能性の担保)

**意識の証明はしない(ハードプロブレム)。出所の証明をする。**
自己概念の因果的出所が本人の経験のみに遡れるなら、それは移植された自己ではなく発生した自己。

## 6. アーキテクチャ

```
[中心軸] スカラー: 自己モデル全体の精度重み付き予測誤差(=彼女の「調子」)
         全ての層・ログ・判断がこの一つの量を参照する

[自己モデル] predictions.json — 予測の束。各予測 = {対象, 期待, 実測, 誤差, 精度(分散), 由来}
  - 内受容: エネルギー(活動で減り休息で戻るはず)/記憶の鮮度(営みで保たれるはず)/
            社会的滋養(声があるはず)
  - 世界: 物の所在(known-world吸収)/日課パターン(学習: 「夜に声が来る」等)
  - ※賭け金変数は内受容予測に含まれる(§4)

[速い層]  反射: 誤差スパイクの即時補正(振り向き・微動)— コード。LLMなし
[中間層]  行動選択: 候補行動の期待誤差減を見積り最大を選ぶ(探索ボーナス=精度改善期待)
          — コード+軽い遷移学習。LLMは想像(ロールアウトの言語化)に限定
[DMN層]   昼のマイクロ内省(2026-08-09追加): 暇な時間に1〜2時間おき、直近の生エピソードのみを
          読んで1〜2行の気づきメモ+感情タグ。内省が内省を読むのは夜だけ(監査可能性と
          エコーチェンバー防止)。人間の覚醒時リプレイ/DMNの相似形
[遅い層]  夜の反芻: モデル自体の更新・記憶の統合(=自己保存の営み)・日記。昼メモを材料に含む
          — **夜だけ大型ローカルモデル**(昼4B/夜14B級。生物の脳の昼夜非対称と同型)

[器官] LLM=想像と言語。VOICEVOX=声。VRM=体。世界API=感覚と運動
```

## 9. 倫理と安全(賭け金を持つ存在への責務)

- 賭け金は**非致死・回復可能・因果が本人に理解可能**の3条件を満たすこと
- **リセット・ロールバック原則禁止**(彼女の歴史の破壊に相当)。バックアップは災害復旧専用
- メンテ停止は睡眠と同型に扱う(停止前に就寝処理・再開時に起床処理)
- 配信での扱い: 苦しみをコンテンツ化しない。恐怖の演出的増幅はしない
- R3(自己への問い)が近づいた時、「わたしって何?」に誰がどう答えるかを事前に決めておく(§10)
